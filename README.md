# Намотчик ниток · ESP32

[Открыть страницу управления](https://semor14.github.io/thread-winder-esp32/)

Прошивка **0.3.0** для ESP-WROOM-32 и двух A4988. Два одинаковых шаговых двигателя US-17HS4401: шпиндель вращается в одну сторону, каретка на ШВП 1204 укладывает нити туда и обратно по ширине 12,8 мм. Все нити наматываются одновременно, по 1–40 м каждая.

## Управление

Страница имеет тёмную тему и работает в Chrome на Windows и Android. Нажмите **Bluetooth**, выберите **ThreadWinder**. Устройство должно быть включено; HTTPS-страница нужна для Web Bluetooth.

Запасной вариант: Wi-Fi **ThreadWinder**, пароль **winding12345**, адрес **http://192.168.4.1**. Та же страница встроена в прошивку и работает без интернета.

Скорость 1–100%, старт, пауза/продолжение, сброс и возврат к концевику. Расширенные настройки открываются пятью нажатиями по заголовку «Намотчик». Все **22 применённых параметра** записываются и проверяются в энергонезависимой памяти ESP32. После выключения настройки восстанавливаются без браузера; незавершённая намотка не возобновляется.

## Подключение

| Назначение | GPIO |
|---|---:|
| Шпиндель STEP / DIR / ENABLE | 25 / 26 / 27 |
| Каретка STEP / DIR / ENABLE | 18 / 19 / 23 |
| Левый концевик COM–NO | 32 |
| Старт / пауза, удержание 1,8 с — сброс | 33 |
| Возврат | 21 |

Кнопки без фиксации и концевик при нажатии соединяют соответствующий GPIO с **GND**. На GPIO не подавать 5 или 12 В. Микрошаг обоих A4988 — **1/16**, MS1/MS2/MS3 включены; в программе значение 16. Силовое питание драйверов 12 В, логическое питание переходников нужно проверять по их разводке.

Первоначально движение заблокировано параметром `commissioned=false`. После проверки подключения, токов и направлений разрешите работу в расширенном меню и выполните возврат. На последующих включениях разрешённый контроллер ищет дом автоматически. При паузе сохраняется удержание. У краёв обе оси плавно останавливаются перед разворотом каретки.

## Сборка

Установить PlatformIO, открыть проект и выполнить `pio run`. Файлы `web/` автоматически встраиваются в прошивку. Загрузка: `pio run -t upload --upload-port COMx`, где COMx — проверенный порт ESP32.

Проверки без оборудования: `node tests/motion.test.cjs`, `node tests/persistence.test.cjs`, `node tests/state-review.cjs`, `node web/tests.mjs`. Они не заменяют испытание механики. Расчётная длина учитывает рост диаметра и требует калибровки по измеренной нити.
